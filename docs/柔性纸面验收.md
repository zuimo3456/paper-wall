# 柔性纸面修订

## 修改原因与实现

上一版把整张纸当作刚性平面旋转，无法表现参考视频的局部卷曲。本版替换为顶部固定的柔性条带：根据抓取点求解长度约束、轻微弯曲约束和阻尼，用共用边界的投影面片映射纸面文字，渲染背面和变化的投影。

- 静置时没有规则整张摆动。
- 拖动纸面空白处可拉起局部纸面；右下角纸角可轻掀一次。
- 上沿用于移动整张流程纸，仍保存原有坐标。
- 输入与表单保持原生交互；动画副本设为 aria-hidden、inert，无重复焦点。
- 仅活动纸张运行动画，回落后销毁面片；减少动态设置下不创建动画。
- 同一数据库、无登录访问与已保存事项均不改动。

## 验证

- 物理约束7个用例通过：30/60/120Hz下顶部固定、纸身明显离墙、数值有限、接触墙面、释放后回到静置，以及拖动惯性。
- TypeScript检查通过。
- 浏览器观察到实际局部卷起，最大深度约177px；根纸张的旋转保持固定，面片数量随纸张高度和设备调整。
- 待办数字输入、新增、勾选归档正常。
- 新增两阶段流程、阶段勾选正常；拖动上沿后刷新，坐标650、86.46及已完成的第一阶段均保留。
- 393×852下纸角入口可用，观察到完整卷曲/回落；仅验证浏览器手机尺寸，安卓真机帧率未实测。
- 浏览器未发现脚本错误。
- `outputs/柔性纸页预览.gif` 为手机尺寸浏览器实际画面的截图序列。

## 范围

这是柔性条带近似，支持连续卷曲、背面和投影；参考视频中完整的二维揉皱/复杂褶皱尚未完全复现。
