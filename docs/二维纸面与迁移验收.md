# 二维纸面与独立部署验收（2026-11-07）

本次替代上一版条带近似。二维网格同时求解纵向、横向、剪切与弯曲约束，抓取位置使用渲染三角形的重心坐标约束，拖动时抓住一个局部点。松手后阻尼回落，静置时销毁渲染实例。上沿仍用于移动整张纸，纸面空白区域用于抓起纸面。

胶带与纸面在同一个 WebGL 深度缓冲内绘制；胶带贴近墙面，卷起的纸面可自然遮住它。动画期间隐藏原 DOM 胶带，避免它以高层级覆盖折起纸面。原生文字、输入框与辅助功能结构保留，动画层不接收焦点。无 WebGL 或系统启用减少动态时保留可编辑静态纸面。
