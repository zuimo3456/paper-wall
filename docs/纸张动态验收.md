# 纸张动态增强

## 实现

- 近期事项和流程纸静置时均绕上沿轻摆，纸张采用不同周期和相位。
- 鼠标移动、按压与轻拉纸面改变俯仰、侧倾与底部翘角，阴影随姿态改变。
- 拖动上沿时按移动速度倾斜并抬离墙面；松手后使用衰减回摆返回静置姿态。
- 动画姿态不写入数据库；原有纸张坐标保存逻辑保留。
- 输入时暂停；鼠标悬停时暂停静置摆动以便点击；触屏不使用可能粘滞的 :hover 暂停。
- 动态通过原生 CSS 和 Web Animations 执行，pointermove 不触发 React 状态更新。
- 系统减少动态设置下关闭装饰动画；双指墙面手势可打断纸面按压。

## 浏览器验证

- 静置样式为 paper-appear、paper-air，运行中 --paper-air 随时间变化，transform 为实际3D矩阵。
- 轻触近期事项后读到非零俯仰与旋转，并发生回弹；未发现浏览器脚本错误。
- 输入待办时 paper-writing 生效、idle 暂停，新增待办、勾选归档正常。
- 创建流程纸、拖动后读到约 -9.8° 俯仰与 -3.4° 旋转；松手后回摆。
- 刷新页面后拖动坐标仍为 700.59、75.5419；阶段勾选正常。
- 393×852下纸张与操作入口布局正常；测试为浏览器手机尺寸，真实安卓触控手感仍需实机体验。
