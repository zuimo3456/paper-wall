# 自然回落与整条上沿拖动（2026-11-07）

本次替代上一版所有松手动作都进行快速恢复的策略。

- 正常松手不再逐帧混合到初始形状，不再在 1.8 秒时强制拉平，也不再到 6.5 秒直接切回静态 DOM。保留惯性并使用较轻阻尼；降低松手后的弹性牵引和重力，只有实际静止后才结束渲染。
- 大幅折叠在松手一段时间后持续停滞，才启动缓入缓出的慢速舒展；该纠正不转化为新的弹射速度。重新抓住时立即中断该兜底处理。
- 整条上沿按纸张本地坐标命中，包括裸露左右角及凸出纸张的胶带。搬动事件由纸张本身捕获，不再依赖内侧标题容器的矩形。下方纸面继续局部弯曲，输入和按钮继续保留各自交互。
