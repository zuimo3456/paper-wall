# 自动找空位、缠绕恢复与重影修复（2026-11-07）

## 行为

- 新增、恢复归档、归档后立即撤销，以及编辑后尺寸变大的流程纸，会按实际渲染尺寸寻找空位。复用同一个纸张组件在不可见区域测量换行后的标题、说明和阶段，不按阶段数量猜高度。
- 碰撞区域包含纸张旋转、伸出的胶带和阴影，并额外留 28px 间距。优先保留原位置；位置被占用时就近寻找空白。没有足够空间时保留编辑内容或归档状态，不强行叠放。
- 连续恢复按顺序安排，操作前重新读取共享墙面。新增或恢复普通待办导致近期事项纸增高时，近期事项也会避让；全览按真实纸张尺寸计算。
- 缠绕检测改为检查是否持续向原形展开，覆盖仍在抖动但没有恢复进展的折叠。保留正常松手的轻柔回落，异常时慢速舒展；修正高刷新率下的时间步下限。
- 动画状态使用独立的 `data-flexing` 标记。React 更新选中纸张的 className 时，底层原纸仍被隐藏，避免同时出现两份内容。生成贴图的克隆会移除此标记。
