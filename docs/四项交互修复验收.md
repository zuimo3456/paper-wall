# 四项交互修复（2026-11-07）

## 修复

1. 释放后在物理阻尼之外渐进恢复原始网格，避免距离约束陷入打结的局部平衡；1.8 秒内完成形状恢复。移除每次鼠标移动额外推进物理的行为，减少事件频率导致的差异。窗口失焦、页面隐藏、失去指针捕获、指针取消、移出后鼠标已松开，都会结束抓取。
2. 将逐字重绘的纸面截图改为浏览器原生渲染计算样式，使用与静态 DOM 相同的字形、间距、纸纹与纸角；胶带同样从实际样式取材。静止平面的着色倍率为 1，弯曲只产生轻微哑光明暗。提高贴图分辨率，仍限制纹理尺寸和活动实例数量。原生快照失败时保留静态纸，不隐藏内容。
3. 近期事项上沿增加拖动区域和抓手。位置作为固定 ID 的布局记录保存在原数据库，使用相同的版本冲突保护；刷新、跨设备读取、备份导出和独立版导入都会保留。没有布局记录的旧数据继续默认放在左上角。布局不进入待办、流程和归档列表。“回到近期事项”和“全览”读取实际位置。
4. 禁用纸面的文字选中与浏览器原生拖放，使用 Pointer Events 接管纸面抓取；输入框仍可正常编辑。事项文字和纸角支持拖动，轻点仍分别进入编辑或掀纸角；移动超过阈值才捕获按钮指针，避免吞掉点击。可命中原纸张矩形外已翘起的网格；移出纸张仍继续跟踪鼠标。编辑、勾选、输入与上沿搬动保持各自操作。
